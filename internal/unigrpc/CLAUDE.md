# UniGRPC Package

Unidirectional gRPC transport.

## Purpose
Provides unidirectional streaming using gRPC protocol for server-to-client messaging.

## Files
- `grpc.go` - gRPC service implementation
- `transport.go` - Transport interface implementation
- `config.go` - Configuration structure
- `codec.go` - gRPC codec configuration
- `unistream/` - Protocol buffer definitions

## Features
- High-performance gRPC streaming
- Protocol buffer message format
- Bi-directional streaming capabilities
- Strong typing with protobuf
