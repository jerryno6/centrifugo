# Tools Package

Development and testing utilities for Centrifugo.

## Purpose
Collection of helper utilities used across the codebase for development, testing, and operations.

## Files
- `ascii.go` - ASCII art and branding utilities
- `compare.go` - Comparison utilities for testing
- `config.go` - Configuration testing utilities
- `file.go` - File system utilities
- `logging.go` - Logging utilities for tests
- `pid.go` - Process ID file management
- `test_helpers.go` - Common test utilities
- `code_translate.go` - Code translation utilities

## Usage
These tools are primarily used in tests and development scripts to provide consistent utilities across the codebase.
